A demo usually ships invented fixtures, and a reader can tell. This one ships the real
thing: every decision in this project got a ticket, including the ones that were wrong,
and the conversations on them are the actual exchanges between a person and the agents
doing the work.

## Why it matters more than it sounds
It is the only way to show the two registers doing their job. A fixture with three tidy
comments cannot demonstrate a feature that exists because agent output is long and
arrives fast -- you have to see a ticket with a two-line human exchange and a
twenty-line agent analysis folded underneath it.

So: anything done to this project gets a ticket, as it happens. That is not bookkeeping,
it is the demo.
